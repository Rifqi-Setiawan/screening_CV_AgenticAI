Arsitektur Matching & Evidence Retrieval Engine pada platform AI CV Screening memerlukan transisi fundamental dari paradigma Symmetric Lexical-Semantic Similarity (SCORING_MODE="rules" + threshold kosinus statis) menuju Asymmetric Taxonomic Retrieval & Natural Language Inference (NLI) Entailment Engine.

Dokumen rancang bangun ini merinci cetak biru arsitektur, formulasi matematis, skema basis data, serta implementasi kode untuk mengeliminasi False Negative (kasus competent candidate dropped to Band C) sekaligus menjaga presisi ketat terhadap False Positive.

1. Executive Diagnosis: Mengapa Sistem Saat Ini Mengalami False Negative Sistemik?

Secara komputasional, kegagalan mendeteksi pengalaman kerja yang relevan (False Negative / NOT_DEMONSTRATED) disebabkan oleh empat cacat struktural pada desain pipeline generasi pertama:

Asimetri Taksonomi (Hiponimi vs. Hipernimi) pada Ruang Vektor Bi-Encoder:
Model bi-encoder seperti Harrier-270m memetakan teks ke ruang vektor berdimensi 640 berdasarkan kemiripan topik simetris, bukan implikasi logis satu arah (directional entailment). Dalam bahasa alami rekrutmen:

Kualifikasi JD (Hipernim / Abstraksi): "Mampu menyampaikan dan mengimplementasikan kurikulum Pendidikan Agama Islam" atau "Database Administration & Architecture".

Bukti CV (Hiponim / Instansiasi Konkret): "Mengajar materi tahfidz, fiqih ibadah, dan akidah akhlak kelas 7-9 SMP" atau "Merancang skema tabel, optimasi query relasional, dan migrasi basis data pelanggan".

Kriteria JD umumnya berupa frasa nomina pendek (3–8 kata), sedangkan bullet point CV berupa klausa tindakan majemuk (12–35 kata). Penyatuan (mean/EOS pooling) pada bi-encoder mendilusi bobot kata kunci inti pada kalimat panjang.

Amputasi Konteks Struktural (Orphan Bullet Embedding):
Memotong pengalaman kerja per baris bullet tanpa menyertakan metadata induk (Jabatan, Industri Perusahaan, Durasi) menghilangkan sinyal disambiguasi. Kalimat "Melakukan audit kepatuhan standar operasional" memiliki makna semantik yang sama sekali berbeda jika dilakukan oleh seorang Quality Assurance Manufacture dibandingkan Legal Counsel.

Ketergantungan pada Pohon Kata Kunci Statis (skills.yaml & kind_rules.py):
Aturan berbasis regex dan kamus statis tidak memiliki sifat domain-generalization. Ketika platform digunakan lintas industri (Pendidikan, Sipil, Hukum, Medis, F&B), ruang kosakata tumbuh secara kombinatorial dan menyebabkan rule-gating menolak bukti valid sebelum sempat dievaluasi secara mendalam.

Tiga Aksioma Arsitektur Baru

Context-Preserving Late/Prefix Representation: Setiap unit bukti (bullet point) wajib membawa konteks jabatan, domain organisasi, dan rentang waktu saat diproyeksikan ke ruang vektor, namun tetap menyimpan span teks aslinya secara terpisah untuk highlighting UI.

Recall-Then-Precision Funnel (Multi-Tier): Pisahkan fase Pencarian Bukti (fokus pada Recall mendekati 100% melalui Dynamic Query Expansion dan Hybrid RRF) dari fase Verifikasi Kualifikasi (fokus pada Precision tinggi menggunakan Cross-Encoder dan NLI Entailment).

Sub-Aspect Evidence Aggregation: Satu kualifikasi JD jarang terpenuhi oleh satu kalimat tunggal di CV. Evaluasi harus mampu menggabungkan (aggregate) beberapa bullet point lintas pengalaman kerja untuk membuktikan satu kriteria komposit.

2. Hierarchical Contextual Chunking & Document Representation

Untuk mengatasi Context Loss, proses parsing CV tidak boleh lagi menghasilkan daftar kalimat lepas (flat chunks). Kita menerapkan skema Parent-Child Contextualized Chunking dengan pemisahan tegas antara raw_verbatim_text (untuk tampilan audit HR) dan contextualized_embedding_text (untuk input model vektor dan reranker).

2.1. Skema Representasi Hirarkis (Parent-Child Document Graph)

Setiap entri pengalaman kerja direpresentasikan sebagai graf dua tingkat:

Level 1 (ExperienceParent): Menyimpan entitas tempat konteks bernaung: job_title, normalized_role_category, organization_name, inferred_industry, start_date, end_date, duration_months.

Level 2 (EvidenceChild): Setiap bullet point atau klausa tindakan kohesif di bawah ExperienceParent tersebut, dilengkapi penanda posisi karakter (char_start, char_end) terhadap dokumen CV asli.

);

-- Tabel Child: Unit Bukti Terkontekstualisasi (Atomic Evidence Unit)
CREATE TABLE cv_evidence_units (
    evidence_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    parent_id UUID NOT NULL REFERENCES cv_experience_parents(parent_id) ON DELETE CASCADE,
    candidate_id UUID NOT NULL,
    sequence_order INT NOT NULL,
    
    -- Teks murni untuk ekstraksi bukti deterministik & UI Highlighting

    char_start INT NOT NULL,
    char_end INT NOT NULL,

    -- Dense Vector (Harrier-270m 640 dimensi)
    embedding vector(640) NOT NULL,
    
    -- Sparse Lexical Vector (Bilingual Indonesian + English Full-Text Search)
    fts_vector tsvector GENERATED ALWAYS AS (
        to_tsvector('indonesian', contextualized_text) || 
        to_tsvector('english', contextualized_text)
    ) STORED
);

CREATE INDEX idx_cv_evidence_candidate ON cv_evidence_units(candidate_id);

from __future__ import annotations
import math
from dataclasses import dataclass, field
from enum import Enum
from typing import List, Dict, Optional, Tuple
import numpy as np
import torch
from transformers import AutoTokenizer
from optimum.onnxruntime import ORTModelForSequenceClassification


class EvalState(str, Enum):
    STRONG = "STRONG"
    PARTIAL = "PARTIAL"
    NOT_DEMONSTRATED = "NOT_DEMONSTRATED"


@dataclass
class CompiledRequirement:
    req_id: str
    canonical_text: str
    domain_context: str
    concrete_manifestations: List[str]  # Hiponim operasional hasil ekspansi JD
    synthetic_prototype: str            # Kalimat prototipe bukti CV
    vec_canonical: np.ndarray           # (640,) Harrier-270m normalized
    vec_prototype: np.ndarray           # (640,) Harrier-270m normalized
    min_duration_months: int = 0


@dataclass
class CandidateEvidenceUnit:
    evidence_id: str
    parent_id: str
    job_title: str
    organization_name: str
    duration_months: int
    raw_verbatim_text: str
    contextualized_text: str
    char_start: int
    char_end: int
    embedding: np.ndarray               # (640,) Harrier-270m normalized
    sparse_bm25_score: float = 0.0


@dataclass
class ProvenanceAnchor:
    evidence_id: str
    parent_id: str
    job_title: str
    organization_name: str
    duration_months: int
    verbatim_quote: str
    char_start: int
    char_end: int
    dense_cosine_raw: float
    dense_cosine_proto: float
    cross_nli_entailment: float
    cross_nli_neutral: float
    cross_nli_contradiction: float
    unit_strength_psi: float


@dataclass
class RequirementEvalResult:
    req_id: str
    state: EvalState
    aggregated_score: float
    confidence_score: float
    matched_duration_months: int
    anchors: List[ProvenanceAnchor] = field(default_factory=list)


class EntailmentMatchingEngine:
    """
    Production Matching & Evidence Retrieval Engine (V2).
    Menggantikan static regex/keyword tree pada kind_rules.py dengan
    Multi-Vector Hybrid Retrieval + Cross-Attention NLI Entailment.
    """

    def __init__(
        self,
        onnx_nli_model_path: str = "MoritzLaurer/bge-m3-zeroshot-v2.0",
        device: str = "CPUExecutionProvider",
    ):
        self.tokenizer = AutoTokenizer.from_pretrained(onnx_nli_model_path)
        self.nli_model = ORTModelForSequenceClassification.from_pretrained(
            onnx_nli_model_path,
            export=True,
            provider=device,
        )
        # Mapping label standar model NLI (Entailment, Neutral, Contradiction)
        self.label2id = {k.lower(): v for k, v in self.nli_model.config.label2id.items()}
        self.idx_entail = self.label2id.get("entailment", 0)
        self.idx_neutral = self.label2id.get("neutral", 1)
        self.idx_contra = self.label2id.get("contradiction", 2)

        # Daftar kata kerja pasif untuk penyesuaian bobot keterlibatan (agency multiplier)
        self.passive_markers = (
            "membantu ", "ikut serta", "berpartisipasi", "mendukung ",
            "assisted ", "participated in", "exposed to", "familiar with"
        )

    @staticmethod
    def build_contextualized_chunk(
        job_title: str,
        org_name: str,
        inferred_domain: str,
        duration_months: int,
        raw_bullet: str,
    ) -> str:
        """Membentuk teks terkontekstualisasi untuk di-embed ke Harrier-270m."""
        org_info = f"{org_name} ({inferred_domain})" if inferred_domain else org_name
        return (
            f"[Jabatan: {job_title} | Organisasi/Bidang: {org_info} | "
            f"Durasi: {duration_months} bln] Bukti Kerja: {raw_bullet.strip()}"
        )

    def _compute_agency_multiplier(self, raw_text: str) -> float:
        text_lower = raw_text.lower().strip()
        for marker in self.passive_markers:
            if text_lower.startswith(marker) or f" {marker}" in text_lower[:35]:
                return 0.72
        return 1.0

    def _tier2_hybrid_candidate_selection(
        self,
        req: CompiledRequirement,
        evidence_pool: List[CandidateEvidenceUnit],
        top_m: int = 8,
    ) -> List[Tuple[CandidateEvidenceUnit, float, float, float]]:
        """
        Tier 2: Menghitung Multi-Vector Dense Score + Sparse Lexical RRF
        dan menyaring Top-M kandidat bukti tanpa membuang kecocokan hiponim.
        """
        if not evidence_pool:
            return []

        emb_matrix = np.vstack([ev.embedding for ev in evidence_pool])  # (N, 640)
        cos_raw = np.dot(emb_matrix, req.vec_canonical)                  # (N,)
        cos_proto = np.dot(emb_matrix, req.vec_prototype)                # (N,)

        # Convex Max-Pooling antara kueri asli dan prototipe hiponim
        dense_scores = np.maximum(cos_raw, 0.96 * cos_proto)

        # Normalisasi skor BM25/FTS
        bm25_raw = np.array([ev.sparse_bm25_score for ev in evidence_pool], dtype=np.float32)
        bm25_max = float(np.max(bm25_raw)) if np.max(bm25_raw) > 0 else 1.0
        bm25_norm = bm25_raw / (bm25_max + 1e-6)

        # Peringkat untuk Reciprocal Rank Fusion (RRF)
        rank_dense = np.argsort(np.argsort(-dense_scores)) + 1
        rank_sparse = np.argsort(np.argsort(-bm25_norm)) + 1
        rrf_score = (0.65 / (60.0 + rank_dense)) + (0.35 / (60.0 + rank_sparse))

        hybrid_scores = 0.75 * dense_scores + 0.15 * bm25_norm + 0.10 * (rrf_score * 60.0)

        # High-Recall Soft-Gating (Floor 0.42 menggantikan static threshold 0.65)
        selected_indices = [
            idx for idx in np.argsort(-hybrid_scores)
            if (dense_scores[idx] >= 0.42 or bm25_norm[idx] >= 0.35)
        ][:top_m]

        return [
            (evidence_pool[i], float(cos_raw[i]), float(cos_proto[i]), float(hybrid_scores[i]))
            for i in selected_indices
        ]

    def evaluate_requirement(
        self,
        req: CompiledRequirement,
        evidence_pool: List[CandidateEvidenceUnit],
    ) -> RequirementEvalResult:
        """
        Mengeksekusi Pipeline Tier 2 -> Tier 3/4 (Cross-Attention NLI) -> Noisy-OR Aggregation.
        """
        candidates = self._tier2_hybrid_candidate_selection(req, evidence_pool, top_m=8)
        if not candidates:
            return RequirementEvalResult(
                req_id=req.req_id,
                state=EvalState.NOT_DEMONSTRATED,
                aggregated_score=0.0,
                confidence_score=0.95,
                matched_duration_months=0,
                anchors=[],
            )

        # Konstruksi Hipotesis yang diperkaya dengan indikator hiponim untuk NLI Cross-Encoder
        manifestations_str = ", ".join(req.concrete_manifestations[:6])
        hypothesis = (
            f"Kandidat terbukti memiliki pengalaman kerja atau kompetensi dalam "
            f"{req.canonical_text} (mencakup aktivitas seperti: {manifestations_str})."
        )

        premises = [item[0].contextualized_text for item in candidates]
        hypotheses = [hypothesis] * len(candidates)

        # Batch Inference menggunakan ONNX Runtime
        inputs = self.tokenizer(
            premises,
            hypotheses,
            padding=True,
            truncation=True,
            max_length=384,
            return_tensors="pt",
        )
        with torch.no_grad():
            outputs = self.nli_model(**inputs)
            logits = outputs.logits.cpu().numpy()
            # Temperature-scaled softmax (tau = 1.15 untuk mencegah overconfidence)
            exp_logits = np.exp(logits / 1.15)
            probs = exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)

        scored_anchors: List[ProvenanceAnchor] = []
        for idx, (ev, c_raw, c_proto, h_score) in enumerate(candidates):
            p_entail = float(probs[idx, self.idx_entail])
            p_neutral = float(probs[idx, self.idx_neutral])
            p_contra = float(probs[idx, self.idx_contra])

            # Perhitungan Unified Evidence Strength (Psi_{i,j})
            dense_best = max(c_raw, 0.96 * c_proto)
            s_nli = p_entail - (0.50 * p_contra) + (0.25 * p_neutral if dense_best >= 0.62 else 0.0)
            s_nli_clipped = max(0.0, min(1.0, s_nli))

            agency = self._compute_agency_multiplier(ev.raw_verbatim_text)
            psi = ((0.65 * s_nli_clipped) + (0.35 * dense_best)) * agency

            # Filter kontradiksi eksplisit
            if p_contra > 0.55:
                psi *= 0.25

            scored_anchors.append(
                ProvenanceAnchor(
                    evidence_id=ev.evidence_id,
                    parent_id=ev.parent_id,
                    job_title=ev.job_title,
                    organization_name=ev.organization_name,
                    duration_months=ev.duration_months,
                    verbatim_quote=ev.raw_verbatim_text,
                    char_start=ev.char_start,
                    char_end=ev.char_end,
                    dense_cosine_raw=round(c_raw, 4),
                    dense_cosine_proto=round(c_proto, 4),
                    cross_nli_entailment=round(p_entail, 4),
                    cross_nli_neutral=round(p_neutral, 4),
                    cross_nli_contradiction=round(p_contra, 4),
                    unit_strength_psi=round(psi, 4),
                )
            )

        # Urutkan bukti berdasarkan Psi tertinggi
        scored_anchors.sort(key=lambda x: x.unit_strength_psi, reverse=True)

        # Multi-Bullet Evidence Aggregation (Diminishing-Returns Noisy-OR pada Top-3 bukti)
        valid_anchors = [a for a in scored_anchors if a.unit_strength_psi >= 0.42][:3]
        if not valid_anchors:
            best_psi = scored_anchors[0].unit_strength_psi
            conf = min(0.99, 0.50 + 0.50 * math.tanh(abs(best_psi - 0.42) / 0.15))
            return RequirementEvalResult(
                req_id=req.req_id,
                state=EvalState.NOT_DEMONSTRATED,
                aggregated_score=round(best_psi, 4),
                confidence_score=round(conf, 4),
                matched_duration_months=0,
                anchors=scored_anchors[:1],  # Sertakan 1 kandidat terdekat untuk log diagnostik
            )

        eta = 0.35
        prod_complement = 1.0
        for rank_k, anchor in enumerate(valid_anchors):
            weight_k = (eta ** rank_k) * anchor.unit_strength_psi
            prod_complement *= (1.0 - weight_k)
        psi_agg = 1.0 - prod_complement

        # Hitung akumulasi durasi unik per Parent Experience
        unique_parent_durations: Dict[str, int] = {}
        for anchor in valid_anchors:
            unique_parent_durations[anchor.parent_id] = anchor.duration_months
        total_matched_months = sum(unique_parent_durations.values())

        dur_ratio = (
            min(1.0, total_matched_months / req.min_duration_months)
            if req.min_duration_months > 0
            else 1.0
        )

        # Penentuan Status Deterministik (State Classification Matrix)
        top_contra = valid_anchors[0].cross_nli_contradiction
        if psi_agg >= 0.68 and top_contra <= 0.20 and dur_ratio >= 0.80:
            state = EvalState.STRONG
            boundary_ref = 0.68
        elif psi_agg >= 0.42:
            state = EvalState.PARTIAL
            boundary_ref = 0.42 if psi_agg < 0.55 else 0.68
        else:
            state = EvalState.NOT_DEMONSTRATED
            boundary_ref = 0.42

        confidence = min(0.99, 0.50 + 0.50 * math.tanh(abs(psi_agg - boundary_ref) / 0.15))

        return RequirementEvalResult(
            req_id=req.req_id,
            state=state,
            aggregated_score=round(psi_agg, 4),
            confidence_score=round(confidence, 4),
            matched_duration_months=total_matched_months,
            anchors=valid_anchors,
        )

7. Benchmarking & Validation Protocol

Untuk membuktikan secara ilmiah bahwa arsitektur baru ini mengeliminasi False Negative tanpa memicu lonjakan False Positive, terapkan protokol pengujian regresi otomatis (tests/benchmark_matching_engine.py) sebelum deployment ke produksi.

7.1. Konstruksi Golden Evaluation Dataset Lintas-Industri

Bangun dataset uji berlabelkan pakar HR (golden_matching_pairs.jsonl) sebanyak minimal 500 pasangan (JD_Requirement, CV_Experience_Set, GroundTruth_State, GroundTruth_Anchor_IDs) yang terdistribusi ke dalam 5 Kuadran Tantangan:

Kuadran 1: Taxonomic Hyponym Match (Kasus Rawan False Negative):

Contoh: JD meminta "Kurikulum PAI" 
↔
↔ CV menulis "Mengajar tahfidz, fiqih, akidah akhlak". Target: STRONG.

Contoh: JD meminta "Database Administration & Architecture" 
↔
↔ CV menulis "Merancang skema tabel, optimasi query, migrasi DB". Target: STRONG.

Kuadran 2: Cross-Lingual & Jargon Paraphrase:

Contoh: JD dalam Bahasa Inggris ("Account Payable & Tax Reconciliation") 
↔
↔ CV dalam Bahasa Indonesia ("Verifikasi tagihan vendor, jurnal pengeluaran kas, dan pelaporan SPT PPh 23/PPN"). Target: STRONG.

Kuadran 3: Multi-Bullet Fragmented Evidence:

Contoh: JD meminta "End-to-end Civil Structural Design & Site Supervision" 
↔
↔ CV memecahnya di Bullet #1 ("Perhitungan struktur beton bertulang dengan ETABS") dan Bullet #5 ("Pengawasan pengecoran dan inspeksi mutu bekisting di proyek lapangan"). Target: STRONG melalui Noisy-OR Aggregation.

Kuadran 4: Lexical Trap / Hard Negative (Pengujian Anti-False Positive):

Contoh: JD meminta "Mengelola kampanye Meta Ads & Google Ads dengan ROAS tinggi" 
↔
↔ CV menulis "Mendesain banner grafis untuk diserahkan kepada tim spesialis Meta Ads & Google Ads". (Kata kunci sama persis, namun peran sebenarnya adalah Graphic Designer, bukan Performance Marketer). Target: NOT_DEMONSTRATED atau maksimal PARTIAL rendah.

Kuadran 5: True Partial / Seniority & Scope Gap:

Contoh: JD meminta "Memimpin arsitektur microservices skala enterprise" 
↔
↔ CV menulis "Membantu bug fixing pada salah satu endpoint layanan microservices selama magang 3 bulan". Target: PARTIAL.
